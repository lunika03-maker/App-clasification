# App-clasification

En este proyecto desarrollamos una aplicación de clasificación de objetos mediante inteligencia artificial, utilizando un modelo previamente entrenado con diferentes fotografías para aprender a distinguir entre un objeto y otro. La aplicación recibe una imagen como entrada y analiza sus características para identificar a qué categoría pertenece, mostrando posteriormente el resultado de la clasificación. Durante el desarrollo se trabajó con la recopilación y organización de imágenes para el entrenamiento de la IA, además de la creación de una interfaz que permitiera al usuario interactuar con el modelo y obtener una respuesta. Este ejercicio permitió comprender de manera práctica cómo los datos visuales pueden utilizarse para entrenar modelos de inteligencia artificial, así como el proceso básico de aprendizaje y reconocimiento de patrones a partir de imágenes.
